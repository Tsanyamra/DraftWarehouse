# DraftWarehouse

DraftWarehouse is a Cloud-based, Intelligent content management engine that auto-scaling clusters for optimized content management and workflow automation.

With DraftWarehouse, you get a lightweight tool that stays out of your way.

**What you get**

- DraftWarehouse is a Cloud-based, Intelligent
- content management engine that auto-scaling
- clusters for optimized content management

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/DraftWarehouse.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DraftWarehouse, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
